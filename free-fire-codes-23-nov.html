How to Redeem (Official Site Only)

Codes cannot be redeemed inside the game lobby. The only official place is Garena's rewards site:

  1. Go to reward.ff.garena.com in your browser.
  2. Log in with the account linked to your game — Facebook, Google, Apple ID, Huawei ID, VK or X. Guest accounts cannot redeem codes.
  3. Paste one code from the list above into the box and hit Confirm.
  4. If it works, your reward lands in your in-game mail within 24 hours.
  5. If it says "expired" or "limit reached", the code is finished — try the next one.

Quick Answers

Do these codes work on Free Fire MAX?
Yes — the codes work on both Free Fire and Free Fire MAX, as long as your account is linked to Facebook, Google or another supported network.

Why did my code say "redemption limit reached"?
Each code is capped at roughly the first 500–1,000 players per server. Once the cap is hit, the code is dead for everyone else, even on the same day.

Can I redeem a code more than once?
No. One code, one claim per account. Trying again just shows the same error.

Is there a code generator that works?
No. Any site or app claiming to "generate" working codes is a scam. Real codes only come from Garena's official channels and events.
