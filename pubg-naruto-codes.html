How to Redeem (The Right Place for Each Code)

  1. Website codes (everything except Naruto): open PUBG Mobile, tap your profile avatar, and copy your numeric Character ID. Go to the official Redemption Center at pubgmobile.com/redeem, enter your Character ID and the code, complete the verification, and tap Redeem. The reward arrives in your in-game mail.
  2. Naruto codes (in-game only): open Events → PUBG MOBILE × NARUTO → NARUTO Gallery Collection → Redeem Code, and enter the code there. They will not work on the website.
  3. If a code fails on the website, first check it is not a Naruto code — then check the mixed-reports note above before assuming you typed it wrong.

Why Your Code Failed

Wrong place: the number one reason — Naruto codes entered on the website always fail. Expired or quota reached: most codes die without warning once their claim limit is hit. Already redeemed: each code works once per account. Region lock: some codes only work on certain servers. Too many attempts: the official page can lock you out until the next day after repeated failed tries. And beware of mixed lists: one popular "verified working today" page mixes Free Fire codes into its PUBG Mobile list — a Free Fire code will never work in PUBG Mobile, no matter how many times you try it.

Quick Answers

Why won't the Naruto codes work on the website?
Because they are event codes, not web codes. They redeem through the in-game NARUTO Gallery Collection event page only — the standard Redemption Center cannot process them.

Are the Naruto codes still working?
Trackers disagree: MMO Culture and PinoyGamer list them as active in November, while BuffHub and GamsGo say the collaboration ended on 7 September 2026 and the codes expired with it. Try them in-game only, and do not count on them.

Where do I find my Character ID?
In PUBG Mobile, tap your profile avatar — your numeric Character ID is shown under your name.

Can I redeem a code more than once?
No. Each code works once per account.

Do PUBG Mobile codes give free UC?
Almost never in large amounts. Be very sceptical of any code promising 1,000 UC — and never enter your password or pay anyone for a code. Real codes only ever go through the official Redemption Center or the in-game event page.
